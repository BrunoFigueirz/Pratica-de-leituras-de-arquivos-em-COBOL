# Desafios COBOL

Exercícios práticos de COBOL, focados em arquivos sequenciais, 
acumuladores e relatórios — base para atuar como programador júnior 
em sistemas mainframe.

## Projetos

- [01 - Salários](./01-salarios) — leitura de arquivo, contadores por categoria
- [02 - Vendas por Região](./02-vendas-regiao) — quebra de controle, subtotais e total geral

## Tecnologias
GnuCOBOL (ambiente local de estudo)
